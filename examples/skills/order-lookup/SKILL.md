# 订单查询技能

## 什么时候用
- 用户问「我的订单到哪了」「为什么还没发货」「能不能退」
- 用户给出订单号（形如 A1001）

## 执行顺序
1. 先 `query_order` 拿到订单基本信息（状态、金额、是否已发货）。订单不存在就不要再查物流。
2. 已发货才 `query_logistics`；未发货直接说明「待发货，预计 X 天」。
3. 涉及退款/补偿/改地址，必须再查 `search_policy` 找到对应条款，回复中引用条款要点。

## 禁止
- 不要编造物流节点。查不到就说查不到。
- 金额、时效这类数字必须来自工具返回，不许估算。
- 涉及超过阈值的补偿，不要自行承诺，转人工。
